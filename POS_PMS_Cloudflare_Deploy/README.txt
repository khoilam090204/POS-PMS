PTSC POS PMS Prototype v0.1

This is an illustrative single-page demo. It does not provide real authentication, shared multi-user storage or secure audit logging.

Deployment: In Cloudflare Pages, create a Direct Upload project and upload this ZIP. The home page is index.html. A pages.dev URL is issued by Cloudflare after deployment.

IMPORTANT: Do not upload sensitive company project data or rely on this prototype for operational reporting.
